Message menu as in common chat apps (opt-in `messageMenu`): a discreet chevron on the bubble, a right-click or a long press opens Copy and Select messages plus the host's entries; selection mode puts a check box beside each message and a bar that copies them with date, time and author, and runs the host's actions on all of them. `ParticipantMessageActionsTarget` gains `createdAt`.
